How to use it

  1. Build the library once. Characters, components (trees, lamps, houses), and backgrounds stay saved. Every later film reuses them.
  2. Write a script. Each scene picks a background. Each line picks a character, an action, a camera, and the words they say.
  3. Generate. That run only rebuilds the voice and scene.js for this script. The Three.js rig and the library are left alone.
  4. Render walks the scene frame by frame in Chrome and muxes the voice into an mp4.
